# Git and GitHub

## What is Git?

Git is a distributed version control system (VCS) that allows multiple people to work on a project simultaneously without interfering with each other's changes. It tracks changes in source code during software development and enables collaboration among developers.

## Commands
- `git init`: Initializes a new Git repository.
- `git status`: Displays the status of the working directory and staging area.
- `git add <file>`: Adds a file to the staging area.
- `git commit -m "message"`: Commits the staged changes with a descriptive message.
- `git log`: Shows the commit history for the repository.
- `git push`
